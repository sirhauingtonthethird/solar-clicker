# Solar Clicker

A tiny cosmic clicker game built with plain HTML, CSS, and JavaScript.

## Play

After the first deployment: https://sirhauingtonthethird.github.io/solar-clicker/

Click the core to gather stardust, chain combos, and buy upgrades. Rare **Solar Surges** set the screen border on fire and multiply each click by **×3.5**.

## Local development

Open `index.html` in a browser. There is no build step and no external dependencies.

## Deployment

Every push or merge to `main` deploys the site to GitHub Pages through `.github/workflows/deploy-pages.yml`.
